Ayuda del administrador

¿Necesitás ayuda con la gestión de THH? Estamos para ayudarte.

Preguntas frecuentes

Resolvé tus dudas sobre la gestión.

¿Cómo puedo agregar un alojamiento?

Desde la sección de gestión de alojamientos, podés cargar la información necesaria para agregar uno nuevo.

¿Cómo puedo modificar un alojamiento?

Buscá el alojamiento que necesitás actualizar y modificá sus datos desde la sección correspondiente.

¿Cómo puedo administrar las cuentas de usuarios?

Desde la sección de usuarios podés consultar la información de las cuentas, según los permisos disponibles.

¿Qué hago si encuentro un problema en la página?

Podés describir el problema en el formulario de contacto para solicitar ayuda.
